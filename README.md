# Light Pen

Локальная настольная доска для рисования, заметок, формул и схем с Fluent Design. Текущая версия исходников — **0.6.0-beta.1**, Windows x64. Tauri v2, Rust, TypeScript, React и Fluent UI React v9; системный WebView2.

В 0.6 добавлены страницы одного пространства, Ctrl+щелчок по ссылкам, личные просмотренные фреймы, переносимые фрагменты, локальные JS/TS-плагины и PNG высокого разрешения/PDF/ZIP всего пространства. В основной строке появился один переключатель страниц; остальные возможности открываются по необходимости. [Руководство 0.6](docs/release-0.6.md), [SDK плагинов](docs/plugins.md), [отчёт проверок](docs/test-report-0.6.md).

Локальный MCP позволяет внешнему ИИ-помощнику читать/редактировать доску, проверять изображение, работать с файлами, страницами, версиями, шаблонами, плагинами, экспортом и общими досками в рамках прав. Один пакет правок — один шаг отмены. Подключение: **Файл → Доступ ИИ**. [Все 25 инструментов и матрица функций](docs/agent-access.md). [Предыдущий выпуск 0.5](docs/release-0.5.md) сохранён отдельно.

Встроенного чата и поля API-ключа нет: модель и аккаунт выбираются в приложении помощника. Чтение/редактирование, рабочая папка и сетевые действия разрешаются явно на время сеанса. Пароли и сохранённые токены не выдаются. Прочитанное помощником содержимое обрабатывается его приложением и выбранным провайдером ИИ.

В 0.4 добавлены аккаунты/гости и совместное редактирование, вложенные группы, стабильные строки/поля таблиц, типы/поиск/сортировка/CSV, расширенные карточки и связанные представления задач. Доступ в Windows сохраняется отдельно с системной защитой. [Руководство 0.4](docs/release-0.4.md), [модель данных](docs/data.md).

По решению владельца выпуск ограничен текущим проверенным набором. Полный дальнейший объём: [план развития](docs/release-0.4-plan.md). Публичный сервис ещё не развёрнут; совместная работа требует отдельно запущенного сервера и его адреса. Размещение и домен выбираются перед запуском сервиса: [инструкция](docs/collaboration.md).

## Запуск

**Бета 0.6 готова к пользовательскому тестированию.** Комплект выпуска: [v0.6.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.6.0-beta.1). Собраны production exe и NSIS, пройдены 209 проверок ядра, 47 Rust, весь набор из 106 различных UI-сценариев, 16/16 групп нативного MCP и проверка в настоящем окне Windows. Условия, показатели, порядок прогонов и ограничения — в [отчёте 0.6](docs/test-report-0.6.md).

Переносимая версия запускается без установки, установщик регистрирует `.lightpen`. Node.js, Rust, отдельный браузер и сервер разработки для локальной работы не нужны. Требуется системный WebView2. Ресурсы и документы работают локально без аккаунта и сети. Упаковка 0.6 создаёт комплект в `builds/0.6.0-beta.1/`; состав и статус — в [first-build.md](docs/first-build.md).

## Возможности

- Перо, маркер и ластик целых объектов. Давление, дополнительные отсчёты пера, настройки сглаживания, стабилизации, минимальной толщины и чувствительности. Интерактивная пробная область.
- Прямоугольник, эллипс, ромб, линия, стрелка, связанные соединители, текст, стикер, фрейм, формула и изображение.
- Стикер собственного размера создаётся протягиванием; щелчок даёт стандартный размер. Стикеры можно растягивать и оставлять пустыми.
- Размер текста 8–256 ползунком и числом, восемь стандартных значений, жирный, курсив и выравнивание. Один жест ползунка — один шаг отмены.
- Формулы LaTeX с предпросмотром, редактируемым исходником, дробями, интегралами и матрицами; локальное отображение и экспорт в PNG.
- Множественное выделение, перемещение, изменение размеров, группы, блокировка, выравнивание, равные интервалы, направляющие, дублирование, внутреннее копирование и порядок объектов.
- Фреймы со списком областей, переходом к ним и отдельным экспортом. Поиск по тексту, стикерам, фреймам и исходникам формул.
- PNG/JPG/WebP из файла, перетаскивания и системного буфера через Ctrl+V.
- Свои цвета и HEX-коды, восемь последних оттенков. Контекстное меню по правой кнопке мыши.
- Масштабирование к указателю, перемещение камеры, сетка, показ всей доски и выделения.
- Сохранение `.lightpen`, отдельные автосохраняемые черновики, недавние доски, резервное восстановление и история версий между запусками.
- PNG всей доски, выделения или фрейма. Воспроизведение текущих объектов с паузой, перемоткой и скоростью 0,5–4×.
- Плоские страницы в одном файле, перенос и копирование между ними, поиск пространства, личные камеры и просмотренные фреймы.
- Переносимые фрагменты через системный буфер и `.lightpen-fragment`; JS/TS-плагины с SDK, командами, диалогами и сохраняемыми виджетами.
- PNG высокого разрешения, PDF страниц/фреймов, ZIP отдельных PNG или общая раскладка пространства; SVG отдельной страницы/области.

Подробности новых функций: [release-0.3.md](docs/release-0.3.md).

## Документы

`.lightpen` — SQLite-контейнер с редактируемыми объектами и встроенными изображениями. Запись выполняется во временный файл в той же папке с атомарной заменой после успешного завершения. Черновик фиксируется раньше отдельного файла назначения. Неудачная запись в выбранную папку не мешает восстановить свежие правки.

Черновики разных досок независимы; предыдущие безымянные доски доступны через недавние. Обычное закрытие дожидается записи. При аварии восстанавливается последняя завершённая запись, без незаконченного жеста.

Запись использует формат 5; читаются файлы 1–5. Старые доски открываются одной страницей. Версии до 0.6 не читают новый формат: для первой пробы используйте копии важных досок. История версий хранит до 20 снимков / 100 МБ на пространство в данных приложения, отдельно от пересылаемого файла. Можно создать снимок вручную; перед восстановлением сохраняется заменяемое состояние. Автоматическая копия предыдущего состояния создаётся при изменениях не чаще раза в минуту.

## Управление

`P/M/E` — перо/маркер/ластик, `V/H` — выделение/рука, `C` — соединитель, `F` — фрейм, `Q` — формула, `T/N` — текст/стикер. `Ctrl+F` — поиск, `Ctrl+G` — группа, `Ctrl+Shift+G` — разгруппировать. Колесо меняет масштаб к указателю, Space с перетаскиванием перемещает доску. Shift ограничивает фигуру/угол, добавляет объекты в выделение и временно отключает направляющие при перемещении.

Двойной щелчок редактирует текст, название фрейма или формулу. Ctrl+Enter завершает текстовый ввод. Системный буфер текста работает в текстовых полях, буфер изображений — на доске. Все основные сочетания перечислены по F1.

Ctrl+щелчок открывает ссылку на странице; Ctrl+Enter — ссылку выделенного объекта. Переключатель страниц содержит поиск всего пространства и меню редких действий. Правой кнопкой по фрейму можно отметить его просмотренным. **Файл → Перенести фрагмент / Импортировать фрагмент / Плагины / Экспортировать** открывает соответствующий диалог.

## Разработка

```powershell
npm ci
npm run tauri -- dev
```

Веб-превью: `npm run dev`. Проверки и сборка:

```powershell
npm run build
npm test
npm run test:e2e
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run beta
npm run test:agent-native
node scripts/package-beta.mjs
```

Для сценариев интерфейса: `npx playwright install chromium --only-shell`. Для Windows-сборки нужны Rust MSVC, C++ Build Tools и Windows SDK. Зависимости закреплены в `package-lock.json` и `src-tauri/Cargo.lock`.

Нативный сценарий агента запускает готовый release exe в отдельном профиле Windows. Отдельный CPU-benchmark команд: `npx tsx scripts/benchmark-agent.ts`. Не запускать нагрузочные измерения одновременно со сборкой или другим тестовым набором.

## Ограничения

Публичный сервис не входит в поставку беты; сервер можно запустить отдельно. MCP требует внешнего клиента и включённого доступа в открытом Light Pen; встроенного ИИ-чата нет. Соединители поддерживают прямой, кривой и прямоугольный маршрут с локальным обходом препятствий. Таблицы принимают TSV/CSV, но не вычисляют формулы Excel и не импортируют .xlsx. Undo действует в текущем сеансе; в общей комнате он отслеживает собственные операции. Постоянные снимки доступны через историю версий. Воспроизведение показывает сохранившиеся объекты в порядке доски, без полной истории удалений и перемещений. Перенос объектов между досками использует файл фрагмента или системный буфер.

Файл ограничен 64 МБ JSON, изображение — 20 МБ и 32 Мп, формула — 4000 символами. PNG ограничен 16 384 пикселями по стороне и 64 Мп; итоговый файл экспорта — 256 MiB, оценка рабочей памяти — 1 GiB. При превышении предела возвращается ошибка без скрытого уменьшения качества. Работа конкретного физического стилуса и драйвера требует аппаратной проверки: автоматические тесты давления синтетические. Другие ОС не проверены.
