# Light Pen: архитектура 0.3

Реализованный стек: Tauri v2, Rust, TypeScript, React, Fluent UI v9 и Canvas 2D. Первая платформа — Windows x64. Системный WebView2 отображает локальные ресурсы в самостоятельном окне. Отдельный сервер приложению не нужен.

## Ввод и отрисовка

Панели React не обновляются на каждый отсчёт пера. Редактор обрабатывает точки рядом с renderer; Rust получает снимки завершённых изменений. Координаты документа отделены от камеры и плотности пикселей экрана. Основная сцена и активный жест рисуются раздельно, по запросу через requestAnimationFrame. В покое непрерывной перерисовки нет.

Контур perfect-freehand строится одинаково для активного и завершённого штриха. Устойчивые блоки по 256 точек имеют перекрытие; пересчитывается хвост до 528 точек. Растровый слой хранит устойчивую часть. Прозрачность маркера применяется ко всему активному слою, без тёмных стыков. Параметры сглаживания, стабилизации и минимальной толщины хранятся в каждом штрихе. Настройки будущих штрихов сохраняются локально.

Отсекаются невидимые объекты, кэшируются границы и контуры. Полностью помещающаяся большая сцена может повторно использовать растровый слой при перемещении. Изменение объектов, масштаба, темы, сетки, размера окна или готовности изображения инвалидирует слой. Кэши сбрасываются при смене документа. Измерения и условия приведены в отчёте; это CPU-время renderer, не физическая задержка пера или гарантия FPS.

Формулы лениво загружают локальный MathJax. Каждый исходник получает отдельный TeX-парсер с ограничением макросов. SVG содержит контуры символов и декодируется как изображение для Canvas. HTML и внешние загрузчики не используются. Экспорт ожидает завершения декодирования; ошибка формулы или картинки останавливает экспорт с сообщением.

## Редактируемая модель

Документ содержит стабильный ID, название, ревизию, время и упорядоченный массив объектов. Камера, выделение, открытые панели и текущий инструмент принадлежат сеансу. Формат 3 сохраняет поля версии 2 и добавляет имена, видимость, угол, виды/маршруты/подписи соединителей, таблицы, задачи, ссылки и порядок слайдов. Чтение версий 1 и 2 сохранено; после редактирования запись получает версию 3.

Соединители ссылаются на ID целевых объектов и сторону привязки. Изменения цели пересчитывают геометрию стрелки; удаление цели освобождает конец с сохранением его последнего положения. При копировании переназначаются ID объектов, групп и внутренних связей. Концы выбранной связанной стрелки можно перетянуть к другой цели.

Группа — общий groupId у объектов одного уровня. Выделение рамкой расширяет группы за линейный проход по сцене. При выравнивании группа считается единицей. Закреплённые объекты исключены из обычного выбора, перемещения, изменения, стирания и удаления; явное разблокирование доступно через контекстное меню и поиск. Фрейм хранит прямоугольную область и название. При перемещении учитывается геометрическое включение содержимого; группа, пересекающая границу, не разрывается.

Одна завершённая операция соответствует записи undo. Ползунок свойств использует временный снимок для предпросмотра без увеличения ревизии на каждом движении; отпускание фиксирует один шаг. Постоянная история версий отделена от undo текущего сеанса.

## Хранение

`.lightpen` — SQLite-контейнер LPEN с версией, метаданными и JSON-снимком объектов, включая встроенные изображения и исходники формул. Числа JSON проходят точный float round trip. Снимок сначала записывается транзакцией во временный файл рядом с назначением, синхронизируется и атомарно заменяет назначение. Будущие неизвестные версии отклоняются без изменения файла.

Каждая доска имеет отдельный черновик и предыдущую копию. Сначала сохраняется свежий черновик и указатель сеанса, затем отдельный файл назначения. Координатор сериализует и объединяет записи; устаревший ответ не объявляет новые изменения сохранёнными. Автосохранение откладывается на время активного жеста, текстового ввода и предпросмотра свойств. Закрытие завершает редактирование и дожидается очереди.

История хранится в `versions/<document-id>/` внутри данных приложения. Новый снимок создаётся вручную либо автоматически для предыдущего состояния не чаще раза в минуту. Список читает только метаданные SQLite; полный документ читается при восстановлении. Хранятся до 20 снимков и 100 МБ на доску, при этом последний снимок сохраняется. Перед восстановлением создаётся снимок заменяемого состояния. Снимки не передаются вместе с отдельным файлом.

В production отсутствует тестовый доступ к объекту редактора. Разрешения Tauri ограничены используемыми оконными и файловыми диалоговыми командами; файлы и формулы обрабатываются как данные. Веб-превью хранит данные в localStorage только для разработки и сценариев интерфейса; готовое приложение использует Rust и SQLite.

## Дизайн и дальнейшие границы

Fluent UI задаёт темы, токены, фокус, меню и диалоги. Сохранены системные оконные кнопки, изменение размера и Snap. CSS-материалы не выдаются за нативный Mica. Инструменты слева, свойства рядом, навигация и настройки справа; панели прокручиваются в небольшом окне.

Поворот, вложенные группы, ортогональная маршрутизация соединителей, шаблоны, совместное редактирование и экспорт PDF/SVG — следующие направления. Работа на macOS/Linux и аппаратное перо требуют самостоятельных проверок.

## Дополнения 0.3

`rotation` измеряется в градусах вокруг геометрического центра объекта. Общая геометрия вычисляет повёрнутые границы и переводит hit-test/непрерывное стирание в локальные координаты. Вращение группы переносит центры вокруг общего центра и поворачивает объекты; Shift даёт 15°. Существующие поля локальных точек штриха не пересчитываются при повороте.

`connectors.ts` даёт один маршрут для Canvas, hit-test, ластика и SVG. У кривой 33 отсчёта кубической геометрии; у прямоугольного соединителя сохраняется локальная ломаная. При изменении сцены оцениваются Manhattan-кандидаты с учётом соседних препятствий. Привязки учитывают повёрнутые стороны целей. Маршрут не гарантирует отсутствия всех пересечений в произвольном графе.

Таблица хранит прямоугольную матрицу строк; задача — статус, дату и пункты со стабильными ID; ссылка — путь, ID назначения и подпись. Табличный вставщик разбирает TSV с кавычками и переносами строк; содержимое никогда не исполняется как формула или код. Сложное редактирование подтверждается одной командой; отмена диалога не меняет документ.

Шаблоны — независимые SQLite-документы в `templates/` данных приложения. Список возвращает метаданные и до 120 лёгких геометрических эскизов без изображений, точек и содержимого таблиц. Полный шаблон читается по проверенному ID при вставке. Переносимый файл использует тот же контейнер с расширением `.lightpen-template`; его запись не меняет указатель сеанса или путь доски.

Миникарта кэширует геометрию отдельно и обновляет рамку камеры без повторного обхода сцены на каждый жест камеры. На обзорных масштабах субпиксельный текст/формулы/карточки заменяются спокойной обзорной геометрией; экспорт всегда использует полную детализацию.

Презентация хранит индекс и временные пометки вне BoardDocument, скрывает рабочую оболочку и включает полноэкранное окно через узкое разрешение Tauri. Выход восстанавливает прежнюю камеру и полноэкранное состояние. Редактор блокирует обычный ввод документа во время показа.

`vector-export.ts` строит собственный контролируемый SVG; пользовательский SVG не исполняется и не импортируется. Формулы используют локальные контуры MathJax, растровые изображения встраиваются, шрифты Noto Sans поставляются с приложением. jsPDF + svg2pdf.js лениво загружаются при PDF-экспорте; каждый фрейм получает страницу и область отсечения, включая повёрнутые фреймы. Масштаб страницы ограничен 14 000 pt по стороне. SVG содержит шрифты; PDF встраивает подмножество используемых символов. Noto Sans в этом выпуске покрывает латиницу, греческий и кириллицу; CJK/эмодзи не являются заявленным покрытием PDF.

Локальная ссылка на доску сначала дожидается сохранения, читает и проверяет целевой документ/объект, затем заменяет текущую доску. Ошибка оставляет исходную работу. Обычный файл открывается системным Explorer после проверки существования локального файла; URL и команды оболочки в этот API не передаются.

Первичные источники API экспорта: https://github.com/yWorks/svg2pdf.js , https://github.com/parallax/jsPDF . Шрифты и OFL: https://github.com/notofonts/noto-fonts . Всё необходимое поставляется локально; внешние загрузки при работе не нужны.
## Нативная доводка 0.3

В презентации renderer отсекает сцену по текущему фрейму, скрывает сетку и рамки других фреймов. Fit учитывает ширину раскрытой контекстной панели. В Windows служебные клавиши браузера отключены через ICoreWebView2Settings3.SetAreBrowserAcceleratorKeysEnabled(false), чтобы F5/Ctrl+R не перезагружали страницу редактора. Текстовые сочетания и навигация остаются доступны. Используется PlatformWebview на главном потоке; Tauri и Windows COM-зависимости зафиксированы совместимыми версиями. Первичный источник: https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings3 .

Кэш большой полностью видимой сцены готовится до её последующего перемещения; кадры после этого используют готовый растр. Проверенный вариант с отложенной подготовкой отвергнут: он ухудшал первые движения до готовности кэша. Одноразовый полный показ 10 000 объектов имеет отдельный бюджет 100 мс, интерактивная отрисовка — p95 16,7 мс. В отчёте обе величины указаны раздельно, без подмены первого кадра прогретым кэшем.

Нативная проверка программного ввода выявила доверенные Windows-события с заполненными key/keyCode, но пустым code. Общий keyboardCode сохраняет физический code, если он доступен, затем распознаёт старший код клавиши и её имя. Один путь используют основные команды, поиск и группы; навигация презентации принимает имена клавиш. Это покрыто отдельными проверками модели и сценарием без физических кодов. Проверка через Windows выполняется настоящим вводом, отдельно от браузерных синтетических событий.
