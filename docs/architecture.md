# Light Pen: архитектура 0.6

Текущая версия исходников — 0.6.0-beta.1. Основа — локальная доска Tauri/Rust/TypeScript; страницы, плагины, переносимые фрагменты и экспорт проходят общую модель, историю и совместную работу. [Контракт и матрица MCP](agent-access.md), [руководство](release-0.6.md), [состояние проверок](test-report-0.6.md). Предыдущий опубликованный [выпуск 0.5](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1) и его отчёты сохранены отдельно.

Формат записи — 5, читаются версии 1–5. `pages` — плоские `{id,title}`, `elements` — глобальная упорядоченная коллекция с `pageId`; ID объектов уникальны в пространстве. Прежние файлы без страниц читаются как `main`; отсутствующий `pageId` относится к первой странице. Перед изменением её порядка legacy-объекты получают явную принадлежность. В `Editor` активная коллекция кэшируется по неизменяемому массиву/странице; глобальная история сохраняет обе коллекции и контекст страницы. `commit` заменяет только активную страницу, `commitWorkspace` — атомарное изменение всего пространства. Камеры/закрепления/просмотренность лежат отдельно от содержимого.

Yjs хранит страницы и их независимые поля/порядок в `Y.Map`. Undo отслеживает метаданные, страницы и объекты. Локальный жест задерживает применение удалённого состояния. Если участники одновременно удалили разные последние страницы, снимок детерминированно создаёт `main`; поздние объекты удалённой страницы сохраняются на выжившей странице. Привязки/обход препятствий рассчитываются по каждой странице отдельно.

Поле `groupPath` хранит цепочку групп от внешней к внутренней, `groupId` сохраняет корень. Копирование переназначает все уровни, строки/столбцы таблицы, пункты задачи и внутренние зависимости; разгруппировка удаляет один уровень, ввод внутри группы наследует её путь. Контекст входа в группу относится к интерфейсу и не сохраняется в документ.

Переносимый фрагмент — версионированный JSON без исполняемого кода; импорт отделяет внешние ссылки/зависимости и переназначает ID. Виджет — обычный `rectangle` с `widget:{pluginId,type,version,data,fallback}`. Отрисовка и экспорт используют fallback даже без установленного плагина. Команды расширений работают с отдельным кандидатом текущей страницы и проверяют ревизию/страницу после ожидания. JS-пакет исполняется в Worker внутри opaque iframe; привилегированный процесс Windows требует отдельного ручного доверия. [Подробности SDK](plugins.md).

Экспорт фиксирует неизменяемый снимок, затем рассчитывает размеры/ресурсы. PNG рисуется из самодостаточного SVG на отдельном холсте; ZIP последовательно упаковывает PNG без повторного сжатия. PDF последовательно добавляет векторные страницы с локальными шрифтами. Ошибки изображений/формул и превышение бюджета возвращаются до итоговой записи. Экранная обводка просмотренности находится только в overlay и не входит в экспорт.

Совместное редактирование использует отдельный сервис Node 24 + SQLite и клиент Yjs. Подробности и оставшиеся ворота публичного развёртывания: [collaboration.md](collaboration.md). Сетевые изменения передают законченные операции. Отдельный UndoManager отслеживает только локальные транзакции. Внешние пакеты во время жеста и редакторов содержимого буферизуются до завершения. Проверка недоверенных CRDT-пакетов выполняется в worker threads с лимитами памяти и времени, очередь сериализует принятие внутри комнаты. Публичный сервис ещё не развёрнут.

Реализованный стек: Tauri v2, Rust, TypeScript, React, Fluent UI v9 и Canvas 2D. Первая платформа — Windows x64. Системный WebView2 отображает локальные ресурсы в самостоятельном окне. Для локальных документов сервер не нужен; встроенного чата или обращения к модели ИИ нет.

## Ввод и отрисовка

Панели React не обновляются на каждый отсчёт пера. Редактор обрабатывает точки рядом с renderer; Rust получает снимки завершённых изменений. Координаты документа отделены от камеры и плотности пикселей экрана. Основная сцена и активный жест рисуются раздельно, по запросу через requestAnimationFrame. В покое непрерывной перерисовки нет.

Контур perfect-freehand строится одинаково для активного и завершённого штриха. Устойчивые блоки по 256 точек имеют перекрытие; пересчитывается хвост до 528 точек. Растровый слой хранит устойчивую часть. Прозрачность маркера применяется ко всему активному слою, без тёмных стыков. Параметры сглаживания, стабилизации и минимальной толщины хранятся в каждом штрихе. Настройки будущих штрихов сохраняются локально.

Отсекаются невидимые объекты, кэшируются границы и контуры. Полностью помещающаяся большая сцена может повторно использовать растровый слой при перемещении. Изменение объектов, масштаба, темы, сетки, размера окна или готовности изображения инвалидирует слой. Кэши сбрасываются при смене документа. Измерения и условия приведены в отчёте; это CPU-время renderer, не физическая задержка пера или гарантия FPS.

Формулы лениво загружают локальный MathJax. Каждый исходник получает отдельный TeX-парсер с ограничением макросов. SVG содержит контуры символов и декодируется как изображение для Canvas. HTML и внешние загрузчики не используются. Экспорт ожидает завершения декодирования; ошибка формулы или картинки останавливает экспорт с сообщением.

## Редактируемая модель

Документ содержит стабильный ID, название, ревизию, время и упорядоченный массив объектов. Камера, выделение, открытые панели и текущий инструмент принадлежат сеансу. Формат 4 сохраняет данные прежних версий, вложенные группы, стабильные ID строк/полей таблиц и расширенные задачи. Чтение версий 1–3 сохранено; запись получает версию 4. Подробности — в [data.md](data.md). Доступ агента не меняет формат.

Соединители ссылаются на ID целевых объектов и сторону привязки. Изменения цели пересчитывают геометрию стрелки; удаление цели освобождает конец с сохранением его последнего положения. При копировании переназначаются ID объектов, групп и внутренних связей. Концы выбранной связанной стрелки можно перетянуть к другой цели.

Вложенность группы задаётся groupPath; groupId сохраняет корень для совместимости. Выделение рамкой расширяет группы за линейный проход по сцене. При выравнивании группа считается единицей. Закреплённые объекты исключены из обычного выбора, перемещения, изменения, стирания и удаления; явное разблокирование доступно через контекстное меню и поиск. Фрейм хранит прямоугольную область и название. При перемещении учитывается геометрическое включение содержимого; группа, пересекающая границу, не разрывается.

Одна завершённая операция соответствует записи undo. Ползунок свойств использует временный снимок для предпросмотра без увеличения ревизии на каждом движении; отпускание фиксирует один шаг. Постоянная история версий отделена от undo текущего сеанса.

## Хранение

`.lightpen` — SQLite-контейнер LPEN с версией, метаданными и JSON-снимком объектов, включая встроенные изображения и исходники формул. Числа JSON проходят точный float round trip. Снимок сначала записывается транзакцией во временный файл рядом с назначением, синхронизируется и атомарно заменяет назначение. Будущие неизвестные версии отклоняются без изменения файла.

Каждая доска имеет отдельный черновик и предыдущую копию. Сначала сохраняется свежий черновик и указатель сеанса, затем отдельный файл назначения. Координатор сериализует и объединяет записи; устаревший ответ не объявляет новые изменения сохранёнными. Автосохранение откладывается на время активного жеста, текстового ввода и предпросмотра свойств. Закрытие завершает редактирование и дожидается очереди.

История хранится в `versions/<document-id>/` внутри данных приложения. Новый снимок создаётся вручную либо автоматически для предыдущего состояния не чаще раза в минуту. Список читает только метаданные SQLite; полный документ читается при восстановлении. Хранятся до 20 снимков и 100 МБ на доску, при этом последний снимок сохраняется. Перед восстановлением создаётся снимок заменяемого состояния. Снимки не передаются вместе с отдельным файлом.

Тестовый доступ к объекту редактора предназначен только для разработки; его отсутствие в готовой production-сборке подтверждено нативным release-прогоном (`productionTestHook=false`). Программный доступ агента работает через проверенный MCP-контракт. Разрешения Tauri ограничены используемыми оконными и файловыми командами; файлы и формулы обрабатываются как данные. Веб-превью хранит данные в localStorage только для разработки и сценариев интерфейса; готовое приложение использует Rust и SQLite.

## Локальный MCP и доступ агента

Один бинарный файл запускается как редактор либо с `--mcp` как stdio-процесс для внешнего клиента. `--profile` выбирает тот же профиль, который открыт в окне. JSON и Codex TOML формируются из реальных путей; секреты в них не попадают. Статический каталог команд обновляется `scripts/generate-agent-catalog.ts` перед build/dev и позволяет обнаруживать инструменты без открытого редактора.

При включении доступа Rust создаёт временный локальный канал на 127.0.0.1, отдельный токен и grant сеанса: чтение/редактирование, выбранная папка и сетевые действия. Описание канала хранится в `agent-session.dpapi` с защитой текущего Windows-пользователя. MCP-процесс обращается к этому каналу; события Tauri передают запросы в AgentController, ответы привязаны к сеансу и запросу. Общего `invoke`, выполнения JavaScript/DOM, shell и чтения хранилища секретов в контракте нет.

Изменяющие запросы защищены session/documentId/expectedRevision/requestId. `edit_batch` подготавливает кандидата, проверяет модель и асинхронные ресурсы, повторно сверяет состояние и фиксирует один результат через обычный Editor/сервисы. Ошибка отменяет весь пакет. Одна фиксация даёт один undo, обычное автосохранение и CRDT-транзакцию. Занятый жест, текстовый или модальный ввод возвращают BUSY; команда не прерывает человека. Файлы/сеть остаются самостоятельными операциями и не объявляются одной атомарной транзакцией доски.

Идентичный повтор получает сохранённую квитанцию; другое содержимое с тем же requestId отклоняется. Журнал ограничен 2048 запросами и 16 MiB. При заполнении нужен новый сеанс, молчаливого вытеснения нет. Чтение не удерживает снимки. Старый доступ отзывается при закрытии или перезагрузке WebView, поскольку новый frontend не имеет прежнего журнала повторов. Отмена запроса во внешнем MCP-клиенте не гарантирует остановку принятой операции; уже завершённая правка при отзыве не отменяется и остаётся доступной обычному undo.

Для больших сцен CandidateValidator проверяет изменённые неизменяемые объекты и кэширует проверенные данные через WeakSet/WeakMap. Точный объём UTF-8 учитывается вместе с границей 64 МБ и ограничениями модели; слабые кэши не удерживают старые документы. Эффект измеряется отдельным `scripts/benchmark-agent.ts`, а не частотой кадров.

Транспорт ограничивает запрос 32 МБ, ответ 8 МБ и обычный текстовый результат 4 МБ. Чтение объектов/версий/шаблонов постраничное; встроенные данные и точки включаются явно. PNG-просмотр ограничен 1600 px и дополнительно уменьшается по объёму; пакет содержит до 200 операций. Запись нового файла требует выбранной папки, существующее назначение — `overwrite=true`; атомарная запись без замены защищает и от появления файла между проверкой и завершением. Ошибка открытия другой доски оставляет исходную работу. Недавние документы читаются через нативную фильтрацию: текущая доска и файлы выбранной папки, без других черновиков. Версии текущей доски и общая локальная библиотека шаблонов доступны без выбора папки.

workspace_ui/close проверяет принадлежность диалога агенту и отсутствие активного ввода человека; ручное переоткрытие снимает принадлежность. Схемы задачи соответствуют допустимым полям модели; endX/endY задают смещения относительно x/y, а не абсолютный конец. CSV/TSV исключает скрытые таблицы, включая прямой выбор ID.

Совместная работа использует текущий или сохранённый доступ приложения и роль сервера. Пароли и сохранённые токены не возвращаются; вход/регистрация выполняются в UI. Сетевое разрешение сеанса обязательно для подключения/приглашений. Запоздалый ответ подключения повторно проверяет сеанс/права и активный жест перед применением к редактору. Модель и аккаунт ИИ находятся во внешнем приложении: Light Pen предоставляет инструменты, а прочитанные данные обрабатываются выбранным клиентом/провайдером.

## Дизайн и дальнейшие границы

Fluent UI задаёт темы, токены, фокус, меню и диалоги. Сохранены системные оконные кнопки, изменение размера и Snap. CSS-материалы не выдаются за нативный Mica. Инструменты слева, свойства рядом, навигация и настройки справа; панели прокручиваются в небольшом окне.

Ниже сохранены подробности дополнений 0.3 и 0.4. Работа на macOS/Linux и аппаратное перо требуют самостоятельных проверок. Полное покрытие текущих функций агентом поддерживается отдельно в [agent-access.md](agent-access.md); новую функцию редактора нужно сразу включать в эту матрицу.

## Дополнения 0.3

`rotation` измеряется в градусах вокруг геометрического центра объекта. Общая геометрия вычисляет повёрнутые границы и переводит hit-test/непрерывное стирание в локальные координаты. Вращение группы переносит центры вокруг общего центра и поворачивает объекты; Shift даёт 15°. Существующие поля локальных точек штриха не пересчитываются при повороте.

`connectors.ts` даёт один маршрут для Canvas, hit-test, ластика и SVG. У кривой 33 отсчёта кубической геометрии; у прямоугольного соединителя сохраняется локальная ломаная. При изменении сцены оцениваются Manhattan-кандидаты с учётом соседних препятствий. Привязки учитывают повёрнутые стороны целей. Маршрут не гарантирует отсутствия всех пересечений в произвольном графе.

Таблица хранит прямоугольную матрицу строк; задача — статус, дату и пункты со стабильными ID; ссылка — путь, ID назначения и подпись. Табличный вставщик разбирает TSV с кавычками и переносами строк; содержимое никогда не исполняется как формула или код. Сложное редактирование подтверждается одной командой; отмена диалога не меняет документ.

Шаблоны — независимые SQLite-документы в `templates/` данных приложения. Список возвращает метаданные и до 120 лёгких геометрических эскизов без изображений, точек и содержимого таблиц. Полный шаблон читается по проверенному ID при вставке. Переносимый файл использует тот же контейнер с расширением `.lightpen-template`; его запись не меняет указатель сеанса или путь доски.

Миникарта кэширует геометрию отдельно и обновляет рамку камеры без повторного обхода сцены на каждый жест камеры. На обзорных масштабах субпиксельный текст/формулы/карточки заменяются спокойной обзорной геометрией; экспорт всегда использует полную детализацию.

Презентация хранит индекс и временные пометки вне BoardDocument, скрывает рабочую оболочку и включает полноэкранное окно через узкое разрешение Tauri. Выход восстанавливает прежнюю камеру и полноэкранное состояние. Редактор блокирует обычный ввод документа во время показа.

`vector-export.ts` строит собственный контролируемый SVG; пользовательский SVG не исполняется и не импортируется. Формулы используют локальные контуры MathJax, растровые изображения встраиваются, шрифты Noto Sans поставляются с приложением. jsPDF + svg2pdf.js лениво загружаются при PDF-экспорте; каждый фрейм получает страницу и область отсечения, включая повёрнутые фреймы. Масштаб страницы ограничен 14 000 pt по стороне. SVG содержит шрифты; PDF встраивает подмножество используемых символов. Noto Sans в этом выпуске покрывает латиницу, греческий и кириллицу; CJK/эмодзи не являются заявленным покрытием PDF.

Локальная ссылка на доску сначала дожидается сохранения, читает и проверяет целевой документ/объект, затем заменяет текущую доску. Ошибка оставляет исходную работу. Обычный файл открывается системным Explorer после проверки существования локального файла; URL и команды оболочки в этот API не передаются.

Первичные источники API экспорта: https://github.com/yWorks/svg2pdf.js , https://github.com/parallax/jsPDF . Шрифты и OFL: https://github.com/notofonts/noto-fonts . Всё необходимое поставляется локально; внешние загрузки при работе не нужны.
## Нативная доводка 0.3

В презентации renderer отсекает сцену по текущему фрейму, скрывает сетку и рамки других фреймов. Fit учитывает ширину раскрытой контекстной панели. В Windows служебные клавиши браузера отключены через ICoreWebView2Settings3.SetAreBrowserAcceleratorKeysEnabled(false), чтобы F5/Ctrl+R не перезагружали страницу редактора. Текстовые сочетания и навигация остаются доступны. Используется PlatformWebview на главном потоке; Tauri и Windows COM-зависимости зафиксированы совместимыми версиями. Первичный источник: https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings3 .

Кэш большой полностью видимой сцены готовится до её последующего перемещения; кадры после этого используют готовый растр. Проверенный вариант с отложенной подготовкой отвергнут: он ухудшал первые движения до готовности кэша. Одноразовый полный показ 10 000 объектов имеет отдельный бюджет 100 мс, интерактивная отрисовка — p95 16,7 мс. В отчёте обе величины указаны раздельно, без подмены первого кадра прогретым кэшем.

Нативная проверка программного ввода выявила доверенные Windows-события с заполненными key/keyCode, но пустым code. Общий keyboardCode сохраняет физический code, если он доступен, затем распознаёт старший код клавиши и её имя. Один путь используют основные команды, поиск и группы; навигация презентации принимает имена клавиш. Это покрыто отдельными проверками модели и сценарием без физических кодов. Проверка через Windows выполняется настоящим вводом, отдельно от браузерных синтетических событий.
