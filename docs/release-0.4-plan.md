# Light Pen — объём беты 0.4 и дальнейший план

3 ноября владелец сократил текущую поставку: «пока что закругляйся и дай стабильную бету. остальное будем позже». Бета 0.4 включает уже реализованный редактор, вложенные группы, таблицы/задачи/представления, совместное редактирование и защищённый доступ. Для неё завершаются исправления, проверки, сборка и выпуск. Полный список ниже сохранён для будущих версий и не является заявлением полноты этой беты. Публичное размещение и домен согласуются перед запуском сервиса.

## Обязательные направления

- [ ] Холст: тачпад, история камеры, закладки, линейки, фон, единицы, предельные координаты.
- [ ] Объекты: лассо, фильтры выделения, перекрытые объекты, системный буфер, вложенные группы, отдельные блокировки, копирование стиля, преобразования.
- [ ] Перо: частичный ластик, профили устройств, наклон/кнопки, режим только пера, фигуры из рукописи, редактирование геометрии, аппаратная приёмка.
- [ ] Векторы: многоугольники, Безье/узлы, скругления, пунктир, градиенты, булевы операции, маски, текст по контейнеру.
- [ ] Связи: ручные точки, подписи на маршруте, наконечники, ветвления, обход, вставка узла, раскладки графов.
- [ ] Диаграммы: UML, ER, BPMN, оргструктура, архитектура, сети, дорожки, легенды, локальные наборы.
- [ ] Mind map: иерархия, клавиатура, сворачивание, автоматическая раскладка, перекрёстные связи, OPML.
- [ ] Текст: оформление фрагментов, списки, индексы, интервалы, шрифты, IME/RTL, поиск/замена, экспорт.
- [ ] Стикеры: пакетная вставка, преобразование списков, автоматический размер, сортировка/группировка, теги и OCR.
- [ ] Документы: структурированный редактор, оглавление, таблицы/код/формулы/изображения, ссылки, Markdown/PDF.
- [ ] Технический контент: расширенный LaTeX, библиотека символов, номера, код/подсветка и Mermaid.
- [ ] Данные: типизированные поля, стабильные записи, фильтры/сортировка/группы, связи, итоги, вычисления, CSV/TSV/XLSX.
- [ ] Задачи: описания, приоритет, даты, подзадачи, зависимости, оценки, теги, напоминания и архив.
- [ ] Канбан: контейнеры колонок, связанные статусы, дорожки, WIP, фильтры и общие данные.
- [ ] Календарь/таймлайн: даты, длительность, вехи, зависимости, шкалы, рабочие дни, экспорт.
- [ ] Графики: столбцы/линии/круг/точки, источник-таблица, оси/легенда, обновление и экспорт.
- [ ] Контейнеры: вложенность, автолэйаут, отступы/интервалы, принадлежность, сворачивание, фреймы и экспорт.
- [ ] Дерево: иерархия, DnD, изоляция, массовые операции, поиск и виртуализация.
- [ ] Медиа: обрезка/маски/замена, OCR/PDF, аудио/видео/метки, вложения и перепривязка.
- [ ] Прототипы: UI-библиотека, экраны, переходы, состояния, компоненты/экземпляры, просмотр.
- [ ] Библиотеки: категории/поиск/предпросмотр, компоненты, версии/параметры и переносимость.
- [ ] Показ: заметки, второй монитор, таймер, произвольная навигация, PDF/PPTX, запись.
- [ ] Сессии: повестка, таймер, голосование, ранжирование, перемешивание, инструкции и фокус.
- [ ] Аннотации: комментарии/ответы, разрешение, фильтры, заметки, поиск, экспорт и история.
- [ ] Ссылки: относительные пути, обратные связи, история, проверка и перенос проекта.
- [ ] Рабочее пространство: проекты/доски/папки/теги, общий поиск, избранное, архив, палитра команд.
- [ ] Хранилище: конфликты окон, версии/сравнение/частичное восстановление, дедупликация, большие документы, переносимые пакеты.
- [ ] Обмен: форматы графики, печать, пакетный экспорт, CSV/Markdown/OPML/JSON/XLSX/PPTX/draw.io, диагностика потерь.
- [ ] Расширения: команды/макросы, локальные плагины, разрешения, изоляция, совместимость и CLI.
- [ ] Локальный ИИ: OCR/рукопись, смысловой поиск/группировка, документы/задачи/диаграммы, аудио, предпросмотр/undo и управление ресурсами.
- [ ] Desktop: окна/вкладки, восстановление, переносимый профиль, локальное обновление, сон/мониторы/DPI.
- [ ] Fluent/доступность: единая панель, контекст, темы/контраст, клавиатура/диктор, масштаб UI, сочетания и локализация.
- [ ] Производительность: пространственный индекс, LOD/кэши, фоновые операции/отмена, память, длительные и аппаратные проверки.
- [ ] Сеть: CRDT, аккаунты, гости, роли, приглашения, курсоры, offline/reconnect, отзыв доступа, защищённое хранение доступа на ПК, повторное подключение после перезапуска, восстановление аккаунтов, долговечность и восстановление сервера.

Каждый пункт включает совместимость с импортом/экспортом, сохранением, undo и совместным редактированием, а не только видимую кнопку. Полный исходный перечень поведения зафиксирован в обсуждении проекта; этот индекс используется для контроля завершения, не заменяет его.

## Очередность внутри одного релиза

1. Совместимая модель и сеть; проверить конкуренцию, отмену собственных изменений, авторизацию и изоляцию комнат.
2. Контейнеры/типизированные данные/богатый текст; затем зависящие от них представления и инструменты.
3. Импорт/экспорт, рабочее пространство, расширения и локальные модели.
4. Общие регрессии, нагрузка, настоящее окно, серверное развёртывание и только затем публикация релиза.

## Сетевые инварианты

- Локальное редактирование не требует сети или аккаунта. Публикация — отдельное явное действие.
- Гость может создать комнату и приглашать по секретной ссылке; аккаунт хранит список своих досок. Право владельца не равно общему приглашению редактора.
- Роли owner/editor/viewer проверяет сервер. Скрытие кнопки не является защитой.
- Приглашения ограничиваются сроком и отзываются; подключённые сессии отзываются тоже.
- CRDT обменивается изменениями, не заменяет целиком чужой документ. Удаление и возврат из offline проверяются отдельно.
- Undo в общей комнате отменяет только собственные операции и не возвращает старый снимок поверх работы других.
- Токены не попадают в .lightpen, шаблоны, экспорт, историю Git и журналы сервера.
- TLS обязателен для публичного развёртывания; обычный HTTP разрешён только для локальной разработки.
- Сервер сохраняет принятое изменение до подтверждения клиенту. Статусы локального и серверного сохранения различаются.
- Изменения прав, вход, восстановление, malformed/oversize сообщения и перегрузка имеют отдельные проверки.

## Ворота готовности

Для текущей беты: нет открытых критических/тяжёлых воспроизводимых дефектов в поставляемом объёме; проверки ядра/хранилища/интерфейса и нативной сборки подтверждены. Исправленные сбои проверяются повторно. Неповторившиеся сбои окружения описываются с исходной трассой и целевым повтором; неизвестную причину не выдавать за установленную. Указываются непроверенное оборудование и ограничения сервиса. Остальные направления перенесены владельцем, полнота всего редактора не объявляется. Для полного будущего релиза остаётся требование завершить все направления либо отдельно пересогласовать их.
