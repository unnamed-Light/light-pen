# Light Pen 0.4.0-beta.1: проверки

Windows x64, 3 ноября 2026 года. По последнему указанию владельца выпущена бета текущего объёма; остальные направления перенесены на будущие версии. Состав: [release-0.4.md](release-0.4.md), дальнейший план: [release-0.4-plan.md](release-0.4-plan.md). Архив предыдущего выпуска: [test-report-0.3.md](test-report-0.3.md).

## Итог

Известных воспроизводимых критических или крупных дефектов в поставляемом объёме после выполненных проверок не осталось. Это не гарантия отсутствия всех ошибок. Публичный сервис не развёрнут; аппаратное перо и длительная эксплуатация сервера требуют отдельной приёмки.

## Производительность и плавность

Финальный набор выполнялся отдельно от компиляции и других тестовых нагрузок. Приложения пользователя не закрывались. Измеряется CPU-работа редактора/renderer в браузерном WebView-подобном окружении, а не частота представления GPU или физическая задержка пера. Пороги не повышались ради прохождения.

| Сценарий | Последний результат |
| --- | --- |
| Полностью видимая смешанная сцена, 10 000 объектов | первый кадр 27 мс: рисование 11,5 мс, растровая подготовка 12,3 мс; p95 камеры 4,6 мс; 25 шагов 439 мс |
| Общая доска, 10 000 объектов и 32 подтверждённые правки | p95 локальной операции 9,9 мс, максимум 18,9 мс; сохранены все 32 версии |
| Шесть профилей плавности | 0 разрывов; отличие активного и завершённого силуэта 0–1,685%; p95 overlay 0,9–5,4 мс; commit 0,3–1,2 мс |
| Масштаб и толщина | 50/100/200/400%: фактическая толщина 4/6/12/24 px |
| Длинный штрих из полного UI-прогона, 10 000 точек | p95 обработки пакета 100 отсчётов 0,5 мс; overlay 2,7 мс; commit 4,2 мс; полных перерисовок сцены во время ввода 0 |

Бюджеты: первый полный кадр большой обзорной сцены — 100 мс, интерактивная отрисовка и p95 локальной операции — 16,7 мс. Одиночный максимум локальной операции 18,9 мс превышает бюджет одного кадра; p95 укладывается. На синтетических медленных диагоналях, быстрых дугах, сменах давления и неоднородных отсчётах разрывов не найдено. Аппаратный нажим, наклон, кнопки и подавление ладони не проверены.

UI-ожидание подтверждения общей доски: p95 1312 мс, максимум 1731 мс. Величина включает сервер, статус интерфейса и период опроса Playwright; это не чистая задержка сети. Мгновенное локальное рисование измерено отдельно. Предыдущие результаты и непройденные попытки сохранены, включая исходный p95 CRDT patch 258 мс и UI p95 40,2/24,4 мс до оптимизаций.

Полный UI-прогон дал 68/70 за 48,3 мин. Сценарий ромба остановился в beforeEach до открытия приложения: в трассе есть промежуток 1 531 200 мс без событий, затем сработал прежний тайм-аут 45 с. Причина паузы окружения не установлена. Второй сбой: холодный кадр 10 000 простых фигур занял 136,9 мс при бюджете 100 мс. Целевой повтор без изменения кода/порогов прошёл: ромб 10,4 с; простой обзор 51,4 мс, p95 камеры 3,8 мс. Последующий финальный смешанный обзор и нагрузка общей доски также прошли. Эти исходные сбои не скрыты и не названы исправлениями кода.

## Исправленные существенные проблемы

- Смешанный обзор выходил за бюджет первого кадра: 127,5–133,4 мс. Убраны дорогие субпиксельные обводки в LOD, камера получила отдельную подписку без перерисовки оболочки React. Экспорт и обычный масштаб сохраняют детализацию.
- Атомарные таблицы/чек-листы заменяли чужие изменения. Введены постоянные ID строк/полей/пунктов и отдельные операции ячеек/текста/полей. Проверены одновременные вставки, удаления, переносы, собственные undo/redo, повторные пакеты и перезагрузка.
- Одновременное удаление последних разных строк/полей оставляло пустую таблицу без рабочего редактирования. Заменяющие идентификаторы теперь материализуются без возврата удалённых данных.
- Подготовка CRDT-правки на большой доске задерживала ввод. Пропускаются неизменённые объекты, порядок и повторная локальная материализация; снимки используют неизменённые сущности и точный UTF-8-размер.
- Сетевой черновик кодировал всю доску после правок. IndexedDB теперь записывает небольшие пакеты; Worker объединяет журнал с проверкой поколения. Проверены миграция v1, одновременная полная запись/объединение, отказ чтения без перезаписи пустым состоянием и повторение неудавшейся записи.
- Сервер повторно декодировал большой документ. Ограниченный Worker-кэш переиспользуется только при полном совпадении подтверждённых байтов; отклонённые/неподтверждённые кандидаты не отравляют следующее состояние. Создание комнаты также валидируется вне главного потока. Квота повторно проверяется после асинхронной валидации.
- Отклонённая локальная команда оставляла промежуточное состояние. Допустимая версия восстанавливается, показывается ошибка; следующая команда и undo работают.
- Предельный ручной год приводил к недопустимой дате таймлайна. Дата проверяется до изменения состояния; крайняя шкала отображается корректно.
- Гостевой доступ терялся после перезапуска, а токен аккаунта мог предлагаться как приглашение владельца. Добавлен отдельный защищённый доступ; сервер сообщает его вид, аккаунт не раскрывает сессию как приглашение. Отключённая локальная копия получает независимый ID.
- Локальные ссылки отклоняют сетевые/относительные/служебные пути, ADS, исполняемые файлы, скрипты и ярлыки до файлового ввода-вывода.
- Исправлена кириллица метаданных Windows-пакета. В Docker source set добавлены недостающие модули; набор проверяется запуском сервера и созданием комнаты во временной папке.

## Windows, файлы и доступ

Проверен именно поставляемый production light-pen.exe, identifier app.lightpen.desktop, версия 0.4.0-beta.1. Для QA заданы отдельные LIGHT_PEN_PROFILE_DIR и WEBVIEW2_USER_DATA_FOLDER внутри reports/native-beta. Пользовательские документы, профиль и работающая предыдущая бета не использовались.

В настоящем окне через Windows-ввод открыта тестовая доска с кириллицей и японскими символами в пути; осмотрены канбан, календарь и таймлайн. Мышью нарисован штрих, Ctrl+S записал файл, Alt+F4 штатно закрыл процесс. Повторный запуск восстановил 5 объектов и штрих; нативное чтение подтвердило сохранённые данные. Production test hook выключен. Собранный cache-worker загружен при действующем production CSP и корректно объединил бинарные Yjs-пакеты.

Создана гостевая копия через UI на отдельном локальном сервере. Получена правка названия/карточки второго клиента; исходящий штрих принят сервером и прочитан вторым клиентом — 6 объектов и 2 штриха. После штатного закрытия/запуска комната повторно открылась кнопкой сохранённого доступа. Нативная команда чтения вернула ту же защищённую запись, открытого тестового токена в credentials.dpapi нет. Все QA-процессы штатно остановлены, отладочный порт закрыт.

Rust-проверки включают атомарную замену, Unicode, круговой проход, ошибки/неподдерживаемые версии без потери текущих данных, независимые черновики, восстановление предыдущей копии, историю и шаблоны, безопасные ссылки, реальное DPAPI-шифрование текущим Windows-пользователем, повреждение и отказ замены файла недопустимым состоянием. Очередь TypeScript сохраняет неудавшиеся изменения для повторения и не перезаписывает нечитаемый vault. Токены не входят в .lightpen, шаблоны, экспорт и CRDT-кэш; пароли не сохраняются.

NSIS собран: 4 878 002 байта; переносимый exe: 13 553 152 байта. Установка в пользовательскую систему не выполнялась. При упаковке manifest.json содержит SHA-256 обоих файлов и исходный commit. Новые файлы используют формат 4, читаются версии 1–3; бета 0.3 формат 4 не открывает.

## Непроверенное и отложенное

- Публичный хост, DNS/TLS, контейнер Linux, длительная многопользовательская нагрузка, мониторинг и эксплуатационное обновление/откат. Docker на этой машине отсутствует; проверка source set не заменяет контейнерную приёмку.
- Физический стилус, драйвер, наклон/кнопки/ладонь; другие ОС и полный аппаратный набор.
- Установка NSIS и цифровая подпись пакета не подтверждены. Проверен запуск готового exe.
- Полный дальнейший функциональный объём, включая богатые документы, новые диаграммы/mind map, расширенные контейнеры, медиа, дополнительные форматы, расширения и локальный ИИ.

Резервная копия сервера проверена через SQLite backup API при активном WAL: integrity_check и восстановление комнат, аккаунтов, сессий и приглашений. Это подтверждает механизм резервирования, но не все эксплуатационные процедуры публичного сервиса.

Команды проверки: npm run build; npm test; cargo test --manifest-path src-tauri/Cargo.toml --lib; npm run test:e2e и целевые Playwright-прогоны; npm run beta; node scripts/package-beta.mjs. Среда: Node 24.19.0, npm 12.0.2, Rust/Cargo 1.97.1 MSVC x64, Windows SDK 10.0.26100.0, WebView2 156.0.4314.58. Зависимости зафиксированы lock-файлами.

Первичные источники DPAPI: [CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata), [CryptUnprotectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptunprotectdata).
