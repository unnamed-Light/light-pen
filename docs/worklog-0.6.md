# Light Pen 0.6 — рабочее состояние

Ветка `release/0.6`. Согласованный объём — `docs/release-0.6-plan.md`. Интерфейс должен оставаться спокойным: постоянным новым элементом служит только переключатель страниц. Остальное — меню и контекстные диалоги Fluent.

## Реализовано в рабочем дереве

- Формат 5: плоские страницы и глобальные ID объектов; активные инструменты ограничены страницей, файл/история — всем пространством. Камеры и закрепления личные.
- Страницы: создание, переименование, порядок, дубликаты, удаление с отменой, перенос/копирование фреймов и объектов, поиск всего пространства. Права просмотра сохраняются.
- Страницы в Yjs: независимые поля и порядок; одновременное удаление разных последних страниц даёт общую восстановленную страницу; поздний объект сохраняется на выжившей странице.
- Ctrl+click и Ctrl+Enter для ссылок; личные просмотренные фреймы и зелёная экранная обводка; переносимые фрагменты/буфер/файлы.
- Плагины JS/TS, изолированный Worker в opaque iframe, декларативный диалог, карточки с данными и fallback; явные разрешения. Отдельный расширенный режим процесса Windows с ручным доверием, Job Object и JSON-lines.
- PNG 1/2/4× и точные размеры, прозрачность/область; PDF страниц/фреймов; последовательный ZIP и PNG-раскладка пространства. Снимок зафиксирован при открытии экспорта; оценка ресурсов без тихого уменьшения качества.
- Каталог MCP расширен с 20 до 25 инструментов; страницы, просмотренность, фрагменты, плагины, экспорт-план. Проверка страницы при ожидании. Восстановление всей версии — один undo.
- Явные локальные профили получают отдельный single-instance identity, чтобы нативная QA не пересылала команды в пользовательский экземпляр.

## Проверки и исправления

- Ядро/сервер/CRDT/контракт/плагины: 209/209, 28 файлов; Rust: 47/47. TypeScript/Vite прошли.
- Основной полный UI без отдельно измеряемой нагрузки: 96/96, 16,6 мин; 0 unexpected/flaky/skipped. UI 1000 страниц и минимального окна включён в этот набор.
- Плагины после ручной визуальной находки: 5/5. Новый тест сначала подтвердил отсутствие текста на холсте, затем проверил пиксели на холсте и в PNG после исправления быстрого пути прямоугольников. Повторены Worker, CSP, тайм-аут, Fluent и сохранение fallback.
- Первый полный UI дал 99/102: исправлены legacy-валидация таблицы и устаревшие ожидания тестов шаблона/неверной формулы; исходные результаты сохранены, после исправлений основной набор прошёл полностью.
- Native debug и первая release-сборка: по 16/16 групп. Реальные файлы, MCP, PNG/PDF/ZIP, страницы/история/фрагменты/просмотренность, CSP Worker, ручной запуск native-процесса, Job Object, UTF-8 и пересечение файловых прав.
- Настоящее окно в отдельном профиле: страницы, штрих мышью, зелёная отметка фрейма, Ctrl+Enter, Ctrl+S и закрытие. SQLite сохранил обе страницы и штрих на правильной странице; пользовательские доски не использовались.

## Завершённая приёмка

Окончательные production exe и NSIS собраны, Rust release — 10 мин 39 с. Готовый exe повторно прошёл 16/16 групп нативного MCP, затем проверен в настоящем окне: текст виджета, обе страницы, сохранённый штрих и личная зелёная отметка после повторного открытия. Приложение после этой сборки не менялось.

Отдельный заключительный нагрузочный набор прошёл 9/9 за 140,4 с без параллельной компиляции/других тестов. 10 000 объектов: камера P95 4,3 мс, первый общий план 77,8 мс; длинный штрих: overlay P95 1,6 мс, 0 перерисовок сцены; шесть профилей плавности без разрывов. PNG 64 Мп сохранён в точном разрешении. Итоговое покрытие UI — 106 уникальных сценариев, все успешны, без unexpected/flaky/skipped.

Полные результаты, исходные находки, условия и ограничения — `docs/test-report-0.6.md`. Упаковка `scripts/package-beta.mjs` записывает commit/контрольные суммы; выпуск `v0.6.0-beta.1` содержит приложение, установщик, отчёт, руководства и два примера плагинов. Проверка публичных бинарных файлов выполняется по SHA-256 упакованного manifest.

Пользовательский экземпляр 0.5, личные доски и приватные источники не изменять и не публиковать. Публичное размещение сервера остаётся отдельным этапом.
