# Light Pen 0.5: рабочее состояние

Дата: 4 ноября 2026 года. Проверки завершены 3 ноября. Ветка: `release/0.5`, целевая версия: `0.5.0-beta.1`.

## Цель

Предоставить внешнему агенту программный доступ ко всем существующим возможностям доски через локальный MCP. Сохранить общую модель, undo, сохранение и CRDT; не заменять доступ управлением мышью. Матрица функций и контракт: [agent-access.md](agent-access.md). Объём редактора 0.4 остаётся основанием беты; будущая полнота Miro и публичное размещение не входят в этот выпуск.

## Реализовано

- Единый каталог из 20 инструментов, схемы всех типов/полей и проверка параметров; статический каталог для нативного процесса формируется из TypeScript-контракта.
- MCP stdio в том же exe (`--mcp`), локальный аутентифицированный мост, DPAPI для секрета текущего пользователя и явный временный сеанс.
- Компактный Fluent-диалог «Файл → Доступ ИИ»: чтение/редактирование, выбранная папка, отдельное разрешение общих досок, JSON и Codex TOML.
- Атомарные пакеты, защита сеанса/документа/ревизии/requestId, квитанции повторов, отказ при незавершённом вводе человека и отзыв после перезагрузки WebView.
- Документы, история, шаблоны, изображения/LaTeX, PNG-просмотр, пять форматов экспорта, представления, презентация/воспроизведение и работа с общей доской в пределах роли.
- Защита путей и атомарная запись без случайной перезаписи, ограничения транспорта/памяти, инкрементальная проверка больших сцен с точным учётом UTF-8.
- Руководство, критерии приёмки, описание архитектуры и отдельный отчёт 0.5. Исторические отчёты 0.4 и 0.3 сохранены.

Пароли и сохранённые токены не возвращаются агенту; вход аккаунта выполняется в приложении. Формат доски остаётся 4, совместимым с 0.4. Встроенного чата/ключа API нет, публичный сервер ещё не развёрнут.

## Подтверждённые проверки

После аудита пройдены 165/165 ядро/сервер/агент (22 файла), 42/42 Rust и 13/13 целевых UI. Заключительный полный набор **85/85** завершён за 18,3 мин без пропусков, неожиданных и flaky-результатов. Предыдущий полный набор 78/78 и целевые 6/6 сохранены отдельно. Подробности и журналы: [test-report-0.5.md](test-report-0.5.md).

Закрыты шесть находок независимого ревью: обход папки через недавние документы; запоздалое сетевое подключение после жеста/отзыва; описание относительных endX/endY; схема задач, отклонявшая допустимые существующие данные; закрытие только принадлежащих агенту диалогов без ввода человека; скрытая таблица в CSV/TSV. Добавлены регрессии ядра/Rust/UI и нативные границы недавних/скрытого экспорта.

Production exe и NSIS собраны: `reports/agent-native-release-build.log`, Rust release 9 мин 28 с. Настоящий release MCP завершил 12/12 групп, `productionTestHook=false`: `reports/agent-native-release-final.log`. В окне Windows проверены Fluent-диалог, JSON/TOML, штрих мышью (8 → 9 объектов), Ctrl+S, штатный Alt+F4 с удалением дескриптора и восстановление после запуска с выключенным доступом ИИ: `reports/agent-native-visual.json`.

Финальная смешанная доска 10 000 объектов: первый полный кадр 66 мс, камера p95 8,2 мс. Перо 10 000 отсчётов: обработчик пакета p95 0,4 мс, активный слой 2,1 мс, commit 2,6 мс, без полной перерисовки сцены. Шесть профилей линии без разрывов; силуэт активного/завершённого штриха отличается на 0–1,685%. Общая доска: локальные правки p95 5,4 мс, подтверждение UI p95 509,63 мс, включая сервер и опрос. Финальный Agent CPU benchmark после полного UI: 24 правки/10 000 объектов, p95 16,88 мс, холодный максимум 77,15 мс. Это чуть выше 16,7 мс и относится к командам/валидации/SHA в Node; обработка пера и renderer измеряются отдельно. Ранние 48,37 → 12,58 мс сохранены в отчёте как предыдущие замеры. Все финальные нагрузки выполнялись без компиляции и других тестов.

## Итог

**Бета 0.5 готова к пользовательскому тестированию.** Полный набор и production-проверки завершены, код приложения после production-сборки не менялся. Комплект выпуска: [v0.5.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1); состав и manifest описаны в [first-build.md](first-build.md).

Физический стилус, установка NSIS, другие ОС и публичное серверное размещение остаются неподтверждёнными; эти границы не заменяются синтетическими тестами. Будущий полный объём Miro не объявляется реализованным этой бетой.
