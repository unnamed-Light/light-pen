# Light Pen 0.5.0-beta.1: доступ ИИ к доске

Версия 0.5 добавляет программный доступ внешнего ИИ-помощника ко всем существующим возможностям редактора. Помощник читает редактируемые объекты, выполняет команды и получает PNG для проверки результата. Модель и аккаунт выбираются в приложении помощника. Встроенного чата, выбора модели и поля для API-ключа в Light Pen нет.

**Бета готова к пользовательскому тестированию.** Production exe и NSIS собраны. Настоящий release MCP прошёл 12/12 групп; приложение проверено в окне Windows с сохранением и восстановлением штриха. Пройдены 165/165 ядро, 42/42 Rust, 13/13 целевых UI и заключительный полный UI **85/85** за 18,3 мин. [Комплект выпуска v0.5.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1), [отчёт проверок](test-report-0.5.md).

## Подключение помощника

1. Запустите настольный Light Pen и откройте нужную доску.
2. Выберите **Файл → Доступ ИИ**. Оставьте разрешение редактирования или выключите его для доступа только к чтению.
3. Для открытия других файлов, новых копий и экспорта выберите рабочую папку. Для подключения общих досок и управления приглашениями отдельно разрешите эти действия. Оба разрешения относятся к текущему сеансу.
4. Нажмите **Включить доступ** и перенесите конфигурацию из окна в приложение, поддерживающее MCP. Для Codex есть отдельный вариант TOML. Light Pen должен оставаться открытым.
5. Попросите помощника прочитать доску, выполнить задачу и проверить её через изображение доски. **Отключить доступ** завершает сеанс.

Окно уже подставляет действительные пути к запущенному exe и профилю. Предпочтительно копировать их оттуда. Пример JSON для клиента MCP, где пути нужно заменить своими:

```json
{
  "mcpServers": {
    "light_pen": {
      "command": "C:\\Apps\\Light Pen\\Light Pen Beta.exe",
      "args": ["--mcp", "--profile", "C:\\Users\\Me\\AppData\\Local\\LightPen"]
    }
  }
}
```

Эквивалент для конфигурации Codex:

```toml
[mcp_servers.light_pen]
command = 'C:\Apps\Light Pen\Light Pen Beta.exe'
args = ['--mcp', '--profile', 'C:\Users\Me\AppData\Local\LightPen']
tool_timeout_sec = 120
```

MCP запускает тот же exe с аргументом `--mcp` как фоновый процесс обмена командами; второе окно доски не требуется. Список команд доступен и при закрытом редакторе, но работа с доской требует открытого приложения и включённого доступа. После закрытия приложения, перезагрузки WebView или отключения доступа сеанс нужно включить заново; конфигурация подключения остаётся той же.

## Что доступно помощнику

Контракт включает **20 инструментов**:

| Задача | Инструменты |
| --- | --- |
| Прочитать состояние, объекты и проверить расположение | `board_read`, `objects_read`, `board_inspect` |
| Создать или изменить объекты, отменить действие, выбрать объекты | `edit_batch`, `history`, `selection` |
| Настроить камеру, стиль и перо | `camera`, `settings` |
| Прочитать таблицы и задачи | `table_read`, `tasks_read` |
| Работать с документами, версиями, шаблонами и изображениями | `document`, `versions`, `templates`, `image_import` |
| Посмотреть результат и подготовить файлы | `board_preview`, `export` |
| Управлять презентацией, воспроизведением и панелями | `presentation`, `replay`, `workspace_ui` |
| Работать с общими досками в пределах предоставленных прав | `collaboration` |

Помощник может создавать штрихи с давлением и настройками пера, фигуры, стикеры своего размера, текст, формулы LaTeX, изображения, таблицы, задачи, ссылки и фреймы. Доступны все поля объектов, вложенные группы, поворот, слои, привязки соединителей, выравнивание, палитры, шаблоны, история, представления задач, PNG/SVG/PDF и CSV/TSV. Точная матрица, параметры, ограничения и соответствие кнопкам редактора находятся в [docs/agent-access.md](agent-access.md).

Например, можно попросить: «Прочитай доску, собери из этих заметок схему, сохрани исходные тексты, соедини этапы стрелками и покажи итог». Для точной работы помощник использует ID, координаты и поля объектов; для проверки — PNG. Аппаратные движения и кнопки физического стилуса не воспроизводятся командами: штрих создаётся как редактируемая геометрия.

## Изменения и права

Один пакет правок — один шаг отмены. Перед применением проверяются все объекты, изображения и формулы; ошибка не оставляет часть пакета на доске. Правки проходят общую историю, автосохранение и совместное редактирование. Во время незаконченного жеста или ввода человека помощник получает состояние занятости и должен повторить попытку позже. Повтор идентичного запроса не создаёт дубликаты; устаревшая ревизия требует повторного чтения доски.

Без выбранной папки помощник работает с открытой доской и её черновиком. Для записи нового файла нужна разрешённая папка; замена существующего файла требует явного параметра перезаписи. Ошибка открытия другой доски сохраняет текущую работу. Разрешение сетевых действий не отменяет роль участника комнаты и проверки сервера.

Пароли и сохранённые токены аккаунта помощнику не выдаются. Вход и регистрация выполняются человеком в приложении; помощник может продолжить уже установленное соединение. Токен нового приглашения возвращается только при явно запрошенном создании приглашения и разрешённых сетевых действиях. Содержимое, прочитанное помощником, обрабатывается его приложением и выбранным провайдером ИИ; Light Pen самостоятельно не отправляет доску модели.

## Сохранённые возможности и совместимость

Сохраняется редактор 0.4: рисование и настройки пера, Fluent Design со светлой и тёмной темами, стикеры своего размера, полная палитра, LaTeX, слои, группы, таблицы, задачи и связанные представления, фреймы, шаблоны, экспорт, презентация, черновики и история версий. Руководство редактора: [0.3](release-0.3.md), [дополнения 0.4](release-0.4.md).

Формат документов остаётся **4**, совместимым с 0.4; чтение форматов 1–3 сохранено. Версия 0.3 формат 4 не читает. История версий, черновики и сохранённый доступ относятся к локальному профилю приложения и не пересылаются внутри файла доски.

Локальная работа не требует сети и аккаунта. Публичный сервер совместного редактирования ещё не развёрнут: для общих досок нужен отдельно запущенный сервер и его адрес, см. [collaboration.md](collaboration.md). Дальнейший объём в духе полного Miro остаётся в [плане развития](release-0.4-plan.md) и не заявляется завершённым этой бетой.

## Границы проверки

Пройдены проверки логики, Rust, целевые сценарии, заключительный полный UI 85/85, измерения отрисовки и MCP с настоящим release-процессом Windows. В production отсутствует тестовый доступ к редактору. Проверены Fluent-диалог и обе конфигурации, штрих мышью, Ctrl+S, штатное закрытие и восстановление доски после повторного запуска с выключенным доступом ИИ. Измерения, исправления и журналы перечислены в [test-report-0.5.md](test-report-0.5.md). Работа конкретного физического стилуса, установка NSIS, другие ОС и публичная серверная нагрузка не подтверждены этими проверками.
