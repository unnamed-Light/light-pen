# Light Pen 0.3: рабочее пространство

Десять принятых возможностей: объекты и слои; вращение; виды и подписи соединителей; библиотека шаблонов; PDF/SVG; миникарта; таблицы; задачи; презентация; локальные ссылки. Дополнительно — полная палитра и непрерывные размеры свойств.

Композиция: узкая лента инструментов слева, одна сменяемая панель рядом. Свойства открываются для текущего инструмента/выделения; навигация, вставка и библиотека используют то же место. Сложные редакторы таблицы и карточки открываются по двойному нажатию. В презентации остаётся только компактная панель управления.

```
Файл   Название / сохранение                       Действия
┌──┬───────────────────┐
│  │ Объекты | Вставка  │                    холст
│  │ или свойства      │
│  │ выбранного        │                         миникарта
└──┴───────────────────┘                масштаб / навигация
```

Палитра: Shell #f3f3f3, Canvas #fafafa, Surface #ffffff, Text #242424, Muted #616161, Accent #0f6cbd; тёмные аналоги из текущих токенов. Segoe UI Variable/Segoe UI для всех рабочих элементов. Панель 248 px, отступы 12/16 px, радиусы 6/10 px, разделители обозначают группы функций. Акцент только для активного инструмента, выделения и главного действия.

Проверка замысла: не добавлять десять кнопок на холст; сохранить тихую Fluent-композицию существующей доски. Отличительная черта — одна панель меняет содержимое в ответ на работу, а документ занимает центр. Анимация только короткого раскрытия, с учётом reduced-motion. Все панели прокручиваются на минимальном окне 800×560; клавиатура и видимый фокус обязательны.

Новый формат 3 читает версии 1 и 2. Скрытие/порядок/поворот/данные таблиц и задач/ссылки хранятся в документе. Черновики презентации и лазер — отдельное временное состояние. Шаблоны сохраняются независимо от доски в локальной библиотеке и переносятся отдельным файлом.
