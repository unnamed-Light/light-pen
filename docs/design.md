# Дизайн Light Pen

Направление: спокойное рабочее пространство Fluent 2 с акцентом на собственно доске. Навык `frontend-design` применяется к композиции и визуальной проверке; Windows/Fluent определяет оформление компонентов.

Палитра светлой темы: фон окна `#f3f3f3`, холст `#fafafa`, поверхность `#ffffff`, текст `#242424`, вторичный текст `#616161`, акцент `#0f6cbd`. Тёмная тема: фон `#202020`, холст `#191919`, поверхность `#2b2b2b`, текст `#f5f5f5`, вторичный `#bdbdbd`, акцент `#479ef5`.

Типографика: Segoe UI Variable / Segoe UI для интерфейса и обычного текста; системный запасной sans-serif. Подписи 12 px, интерфейс 14 px, название 16 px. Стикеры могут иметь более крупный текст, но общую семью.

Компоновка: верхняя строка с эмблемой пера, названием документа и состоянием сохранения; инструменты в узкой плавающей вертикальной панели; компактные свойства у выбранного инструмента; навигация и масштаб снизу. Контент выравнивается по левому краю. В центре новой доски — короткая подсказка к первому действию.

Различимость: синий штрих пера в эмблеме и небольшое синее состояние выбранного инструмента; остальные поверхности нейтральны. Никаких декоративных карточек, рекламных блоков, фоновых градиентов и постоянной анимации. Скругления различаются по уровню: окно, панели, кнопки. Тени только обозначают плавающие панели.

Перед реализацией план сопоставлен с задачей: это рабочий редактор, поэтому приоритетами остаются площадь холста, компактность инструментов, доступность и предсказуемость. Общие рекомендации навыка по выразительным шрифтам уступают явному требованию системного Fluent-интерфейса.
