# Light Pen: актуальная бета-сборка

Версия **0.4.0-beta.1**, Windows x64. По последнему указанию владельца выпущен проверенный текущий объём; остальные направления остаются на будущие версии. [Возможности и управление](release-0.4.md), [отчёт проверок](test-report-0.4.md), [дальнейший план](release-0.4-plan.md).

## Готовые файлы

- builds/0.4.0-beta.1/Light Pen Beta.exe — запуск без установки.
- builds/0.4.0-beta.1/Light Pen Beta Setup.exe — NSIS с регистрацией .lightpen.
- builds/0.4.0-beta.1/TEST-REPORT.md — выполненные проверки и ограничения.
- builds/0.4.0-beta.1/НОВЫЕ ВОЗМОЖНОСТИ.md — руководство.
- builds/0.4.0-beta.1/manifest.json — размеры, SHA-256, исходный commit.

Релиз: [v0.4.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.4.0-beta.1). Предыдущие локальные сборки сохраняются в своих папках. Для работы нужны Windows и системный WebView2; Node.js, Rust и сервер разработки для локальной доски не нужны. NSIS скомпилирован; установка в пользовательскую систему не выполнялась.

## Состав и совместимость

Сохранён редактор 0.3: инструменты, собственный размер стикеров, палитра/ползунки, LaTeX, слои, соединители, фреймы, шаблоны, миникарта, экспорт PNG/SVG/PDF, презентация, локальные ссылки, восстановление и история. Добавлены вложенные группы, стабильные табличные записи и типы/CSV, расширенные задачи и связанные канбан/календарь/таймлайн/обзор, совместное редактирование с аккаунтом или гостем, защищённый доступ Windows.

Новая запись использует формат 4; читаются 1–3. Бета 0.3 формат 4 не читает: для первого знакомства используйте копии важных досок. История и черновики находятся в профиле приложения; доступ к общим доскам хранится отдельно от пересылаемого файла.

Совместная работа требует адреса отдельно запущенного сервера. Публичный сервис ещё не развёрнут; размещение и домен обсуждаются перед запуском. Инструкция: [collaboration.md](collaboration.md). Локальные документы работают без сети и аккаунта.

## Подтверждённые проверки

137/137 ядро/сервер, 35/35 Rust; все 72 различных UI-сценария подтверждены между полным и целевыми прогонами. Исходные два сбоя полного прогона описаны в отчёте. Финальный набор производительности 4/4; смешанная сцена 10 000 объектов: первый кадр 27 мс, p95 камеры 4,6 мс. Готовый exe проверен в настоящем окне Windows с отдельным профилем: файл/штрих/сохранение/закрытие/восстановление, задачи, production Worker, гости, двусторонние изменения, защищённый доступ и повторный вход.

Физический стилус, другие ОС, установка NSIS, контейнеры/TLS и длительная публичная нагрузка не подтверждены. Эти границы не заменяются синтетическими тестами.

Сборка: npm run beta; упаковка после фиксации исходников: node scripts/package-beta.mjs. Все зависимости закреплены lock-файлами.
