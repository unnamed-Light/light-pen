# Light Pen: актуальная бета-сборка

Целевая версия **0.5.0-beta.1**, Windows x64. Добавляется программный доступ ИИ ко всем существующим возможностям редактора через локальный MCP. [Руководство](release-0.5.md), [контракт и матрица функций](agent-access.md), [фактический отчёт](test-report-0.5.md).

**Бета готова к пользовательскому тестированию.** Production exe и NSIS собраны; нативный MCP прошёл 12/12 групп, настоящее окно Windows проверено, заключительный полный UI — 85/85. Комплект выпуска: [v0.5.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1). [Отчёт предыдущей 0.4](test-report-0.4.md) сохранён отдельно.

## Комплект 0.5

Папка комплекта: `builds/0.5.0-beta.1/`.

- `Light Pen Beta.exe` — запуск без установки; тот же файл с `--mcp` обслуживает внешний MCP-клиент.
- `Light Pen Beta Setup.exe` — NSIS с регистрацией `.lightpen`.
- `TEST-REPORT.md` — выполненные проверки и ограничения.
- `НОВЫЕ ВОЗМОЖНОСТИ.md` — руководство.
- `AGENT-ACCESS.md` — подключение MCP, 20 инструментов, права и матрица функций.
- `manifest.json` — размеры, SHA-256 и исходный commit.

Нативные результаты сборки: `src-tauri/target/release/light-pen.exe` и `src-tauri/target/release/bundle/nsis/Light Pen_0.5.0-beta.1_x64-setup.exe`. Комплект выпуска с manifest: [v0.5.0-beta.1](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1). Предыдущие локальные сборки сохраняются в своих папках. Для локальной работы нужны Windows и системный WebView2; Node.js, Rust, отдельный браузер и сервер разработки не нужны. Установка NSIS в пользовательскую систему пока не проверялась.

## Состав и совместимость

Сохранён редактор 0.4: рисование мышью/стилусом, собственный размер стикеров, полная палитра, размеры ползунком/числом, LaTeX, слои, поворот, связанные соединители, вложенные группы, фреймы, шаблоны, миникарта, PNG/SVG/PDF, таблицы/CSV и типы, задачи и связанные представления, презентация, локальные ссылки, черновики/восстановление/история, совместное редактирование с аккаунтом или гостем.

Добавлены 20 MCP-инструментов: чтение и визуальная проверка, атомарные изменения и отмена, документы/версии/шаблоны/изображения/экспорт, настройки/представления и общая доска в пределах прав. Подключение — **Файл → Доступ ИИ**. JSON и Codex TOML формируются из действительных путей запущенного exe и профиля. Пользователь явно разрешает редактирование, файловую папку и сетевые действия на время сеанса. Встроенного чата/API-ключа нет; вход аккаунта выполняется в приложении.

Формат записи остаётся **4**, совместимым с 0.4; читаются 1–3. Бета 0.3 формат 4 не читает. История, черновики и сохранённый доступ находятся в локальном профиле, отдельно от пересылаемой доски.

Локальные документы работают без сети и аккаунта. Совместная работа требует адреса отдельно запущенного сервера. Публичный сервис ещё не развёрнут; размещение и домен обсуждаются перед запуском: [collaboration.md](collaboration.md). Полный будущий объём остаётся в [плане развития](release-0.4-plan.md) и не считается завершённым этой бетой.

## Подтверждённые проверки

После аудита пройдены 165/165 ядро/сервер/агент, 42/42 Rust, 13/13 целевых UI и заключительный полный UI **85/85** за 18,3 мин без пропусков и flaky-результатов. Предыдущий полный UI 78/78 сохранён отдельно. Настоящий release exe прошёл 12 групп MCP, включая все экспорты, файлы, шаблоны, изображения, версии, границы недавних документов, скрытые таблицы и отзыв прав; тестовый доступ в production отсутствует.

В настоящем окне Windows проверены Fluent-диалог, JSON/Codex TOML, рисование мышью (8 → 9 объектов), Ctrl+S, штатный Alt+F4 с удалением дескриптора и повторный запуск: восстановлены 9 объектов и штрих, доступ ИИ выключен. Журналы и исправления независимого ревью — в [test-report-0.5.md](test-report-0.5.md).

Финальная смешанная сцена 10 000 объектов: первый кадр 66 мс, p95 камеры 8,2 мс. Перо 10 000 отсчётов: обработчик пакета p95 0,4 мс, активный слой 2,1 мс, commit 2,6 мс, без перерисовки основной сцены. Шесть профилей плавности без разрывов. Финальный CPU-benchmark 24 команд на 10 000 объектах: p95 16,88 мс, холодный максимум 77,15 мс. p95 немного превышает 16,7 мс и относится к командам/валидации/SHA в Node, а не к renderer. Эти измерения не заменяют аппаратную проверку физического пера и не характеризуют чистую сетевую задержку.

Физический стилус, другие ОС, установка NSIS, контейнеры/TLS и длительная публичная нагрузка не подтверждены. Полные условия и доказательства находятся в отчёте.

## Сборка из исходников

```powershell
npm ci
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run test:e2e
npm run beta
npm run test:agent-native
node scripts/package-beta.mjs
```

Нативный тест запускает готовый release exe в отдельном профиле. После фиксации исходников упаковщик записывает их commit в manifest. Зависимости закреплены lock-файлами. Производительность измеряется отдельно, без параллельной компиляции и других тестовых прогонов.
