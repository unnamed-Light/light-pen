# Light Pen: актуальная бета-сборка

Готовая бета **0.6.0-beta.1**, Windows x64. Production exe и NSIS собраны; окончательный exe проверен в отдельном профиле через MCP и настоящее окно Windows. [Комплект выпуска](https://github.com/unnamed-Light/light-pen/releases/tag/v0.6.0-beta.1), [руководство](release-0.6.md), [MCP и матрица функций](agent-access.md), [SDK плагинов](plugins.md), [фактический отчёт](test-report-0.6.md).

## Комплект

Папка: `builds/0.6.0-beta.1/`. Переносимая сборка запускается без установки.

- `Light Pen Beta.exe` — приложение; тот же файл с `--mcp` обслуживает внешний MCP-клиент.
- `Light Pen Beta Setup.exe` — установщик NSIS с регистрацией `.lightpen`.
- `TEST-REPORT.md`, `НОВЫЕ ВОЗМОЖНОСТИ.md`, `AGENT-ACCESS.md`, `PLUGINS.md` — проверки и руководства.
- `ideas.lightpen-plugin`, `native-stamp.lightpen-plugin` — два открытых примера плагинов; расширенный процесс требует отдельного ручного доверия.
- `manifest.json` — размеры, SHA-256 исполняемых файлов и исходный commit; рядом лицензии.

Результаты компиляции: `src-tauri/target/release/light-pen.exe` и `src-tauri/target/release/bundle/nsis/Light Pen_0.6.0-beta.1_x64-setup.exe`. Предыдущий [выпуск 0.5](https://github.com/unnamed-Light/light-pen/releases/tag/v0.5.0-beta.1), исходники и локальный комплект сохраняются отдельно.

Для запуска нужны Windows x64 и системный WebView2. Node.js, Rust, отдельный браузер и сервер разработки не нужны. Перед запуском новой версии закройте прежнее окно приложения. Первую пробу выполняйте на копии важной доски.

## Состав и совместимость

Сохранены рисование мышью/пером, размеры стикеров протягиванием, палитра и числовые/плавные размеры, LaTeX, слои, группы, поворот, соединители, таблицы и задачи, шаблоны, миникарта, презентация, ссылки, черновики и история, аккаунты и гостевая совместная работа.

Новые возможности 0.6: плоские страницы одного пространства, поиск/перенос между страницами, Ctrl+щелчок по ссылкам, личные просмотренные фреймы, переносимые фрагменты и системный буфер, JS/TS-плагины, качественный PNG/многостраничный PDF/ZIP. Постоянный новый элемент — переключатель страниц; остальные функции раскрываются в меню и контекстных диалогах.

MCP включает 25 инструментов. Для новых возможностей действуют те же роли и сеансовые разрешения; страница включена в защиту от устаревшей операции. Встроенного чата/API-ключа нет; модель выбирается в приложении помощника. Пароли и сохранённые токены не выдаются. Разрешения/запуск привилегированного плагина подтверждаются человеком.

Формат записи **5**, чтение **1–5**. Старое пространство открывается одной страницей; прежние приложения формат 5 не читают. Один файл хранит все страницы. Личные камеры/закрепления/просмотренность находятся отдельно. По завершении системного диалога статус сохранения подтверждается только реальной записью.

Совместной работе нужен отдельно запущенный сервер версии 0.6. Публичное размещение и домен ещё не согласованы. Полный будущий перечень Miro не считается завершённым этой бетой.

## Сборка и приёмка

```powershell
npm ci
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run test:e2e
npm run beta
npm run test:agent-native
node scripts/package-beta.mjs
```

Проверки производительности выполняются последовательно, без параллельной компиляции/другого набора. Нативный сценарий запускает реальный exe в отдельном профиле; явно выбранный профиль имеет отдельную single-instance идентичность, чтобы не затронуть пользовательскую доску. Упаковка требует чистый Git и записывает commit в manifest.

Числа проверок и измерения берите из [отчёта 0.6](test-report-0.6.md). Физический стилус, другие ОС, установка NSIS в пользовательскую систему и публичная инфраструктура не подтверждаются синтетическим вводом или локальными тестами.
