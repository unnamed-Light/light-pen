# Light Pen: актуальная бета-сборка

Версия **0.3.0-beta.1**, Windows x64. Расширение первой локальной беты: [список новых возможностей](release-0.3.md). Сборка и проверки завершены 3 ноября 2026 года; свидетельства находятся в [отчёте](test-report.md).

## Выдаваемые файлы

- `builds/0.3.0-beta.1/Light Pen Beta.exe` — запуск без установки.
- `builds/0.3.0-beta.1/Light Pen Beta Setup.exe` — установщик NSIS с регистрацией `.lightpen`.
- `builds/0.3.0-beta.1/TEST-REPORT.md` — результаты проверок.
- `builds/0.3.0-beta.1/НОВЫЕ ВОЗМОЖНОСТИ.md` — управление и описание функций.
- `builds/0.3.0-beta.1/manifest.json` — размеры и SHA-256.

Предыдущая бета остаётся в исходной папке `builds/`. Новая версия помещена отдельно. Для запуска нужны Windows и WebView2; Node.js, Rust и сервер разработки не нужны. Установщик собран; установка в систему в рамках проверки не выполнялась.

## Объём

Сохранены инструменты предыдущих бет. В 0.3 добавлены все десять принятых возможностей: слои, вращение, виды и подписи соединителей, переносимые шаблоны, PDF/SVG, миникарта, таблицы, задачи, презентация и локальные ссылки; панель одна и сменяемая. Полная палитра HSV/RGB/HEX и ползунки размеров дополняют контекстные свойства. Добавлены ползунок текста 8–256 и точное число, оформление текста, связанные стрелки и редактирование их концов, группы, блокировка, выравнивание, интервалы и направляющие, фреймы с экспортом, поиск, настройки и пробная область пера, история версий, вставка изображений из буфера, свои/последние цвета, контекстное меню, LaTeX с предпросмотром и PNG.

Документ формата 3 хранит новые поля и типы объектов. Старые файлы версий 1 и 2 читаются, после изменения записываются в версии 3. Неназванные черновики, восстановление, резервная копия и атомарное сохранение остаются обязательными свойствами. Формулы работают локально и сохраняют исходник.

## Проверка

Проверяются модель и история редактора, очередь записи, контейнер и история снимков Rust, сценарии интерфейса и отдельные тесты плавности/производительности. Релиз проверяется в настоящем окне Windows и через реальные команды Tauri. Физический стилус не участвовал: синтетические события не подтверждают аппаратную задержку, наклон, кнопки или подавление ладони.

Команды: `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml --lib`, `npm run test:e2e`, `npm run beta`, `node scripts/package-beta.mjs`.

Среда: Node 24.19.0, npm 12.0.2, Rust/Cargo 1.97.1 MSVC x64, MSVC Build Tools 14.44.35207, Windows SDK 10.0.26100.0, WebView2 156.0.4314.58. Зависимости зафиксированы lock-файлами.
