# Light Pen 0.6: согласованный объём

Пользователь разрешил реализацию после обсуждения 4 ноября 2026 года.

- Плоские страницы: создание, дублирование, порядок, удаление с отменой, перенос/копирование объектов, поиск пространства, личная камера. Один файл; старый документ становится одной страницей. Сетевые страницы и изменения идут через CRDT.
- Ctrl+click и клавиатура для локальных ссылок; переключение страницы перед фокусом цели; безопасная ошибка при удалённой цели.
- Личные отметки просмотра фреймов, фильтр, массовые действия. Зелёная рамка постоянной экранной толщины и маркер при отдалении, без попадания в экспорт.
- Переносимые фрагменты: фрейм с содержимым по умолчанию, состав и внешние связи до экспорта; переназначение ID, таблиц/задач/групп/ссылок; системный буфер и файлы.
- Устанавливаемые JS/TS-плагины, SDK, команды/панели/виджеты, менеджер разрешений и версий; статический fallback и данные при отсутствии плагина. Расширенный процесс требует явного широкого разрешения; он не считается изолированным от ОС.
- PNG с реальными масштабами/размерами и прозрачностью; PDF по страницам/фреймам; PNG пространства ZIP либо раскладкой; предварительный расчёт ресурсов и размеров.
- MCP для новых возможностей с ID страницы и защитой от переключения/устаревших данных; команды плагинов ограничены также правами сеанса агента.

Готовность: логика/миграция/CRDT, UI, файлы и изолированная нативная проверка готового exe, отдельные измерения пера/больших сцен; исправление найденных крупных дефектов. Непроверенное оборудование и ограничения экспорта фиксировать честно. Пользовательское пространство IdeasGen не использовать как тестовый профиль.
