# Рабочее состояние 0.4

Ветка release/0.4, версия 0.4.0-beta.1. По последнему указанию владельца выпускается стабильная бета текущего объёма; остальной большой план перенесён на следующие версии. Точный состав — release-0.4.md, окончательные свидетельства — test-report-0.4.md. Ниже сохранена история промежуточных этапов, её ранние счётчики не заменяют финальный отчёт.

## Завершение беты

137/137 проверок ядра и 35/35 Rust. Все 72 UI-сценария подтверждены между полным прогоном и целевыми повторами; два сбоя полного прогона описаны без сокрытия исходных результатов. Финальный набор производительности 4/4: смешанная сцена 10 000 объектов — 27 мс первый кадр, 4,6 мс p95 камеры; общая доска — 9,9 мс p95 локальной операции; шесть профилей пера без разрывов. Добавлены защищённое хранение сессий/приглашений DPAPI и независимый ID отключённой копии.

Скомпилированы production exe и NSIS 0.4.0-beta.1. Поставляемый exe проверен в Windows с LIGHT_PEN_PROFILE_DIR и отдельным WebView-профилем: Unicode-файл, канбан/календарь/таймлайн, рисование, запись/штатное закрытие/восстановление, production Worker, гости, двусторонние правки, зашифрованный доступ и повторное подключение после перезапуска. Тестовые процессы штатно закрыты. Пользовательский профиль не использовался. Публичный сервер и аппаратный стилус остаются непроверенными направлениями.

## Сделано на текущем этапе

- CRDT-клиент и отдельный сервер: аккаунты, гостевые комнаты, ограниченные по сроку приглашения, роли owner/editor/viewer, список досок, членства, отзыв и закрепление за аккаунтом.
- Слияние полей объектов/Y.Text, локальный UndoManager, буферизация пакетов во время жеста и редакторов содержимого, курсоры, offline/reconnect и CRDT-кэш IndexedDB без токенов.
- SQLite WAL/FULL, валидация до записи и подтверждения, сериализация изменений комнаты. Worker threads с ограниченной памятью/временем; ограничения запросов, передачи, очереди и объёма хранилища.
- Резервная копия работающей SQLite через backup API; проверка integrity_check и тест восстановления учётных данных/приглашений/документа.
- Панель Fluent «Совместная работа»: создание, подключение, аккаунт, приглашения и управление выданным доступом. Приглашение — URL с секретом во фрагменте.
- Файлы Docker/Caddy для будущего размещения. Docker на этой машине не установлен; контейнерное развёртывание ещё не проверено. Публичный домен не выбран и сервис не запущен.
- Вложенные группы: формат 4, вход/выход, хлебные крошки, выбор внутри, сохранение иерархии при разгруппировке/копировании, наследование группы новыми объектами и ограничение глубины 32.
- Стабильные строки/поля и CRDT отдельных ячеек; пункты и поля задачи сливаются независимо. Типы таблицы, фильтр/сортировка/итоги/CSV; описание, приоритет, начало, оценка, теги, зависимости и архив задачи. Подробности в data.md.
- Связанные представления существующих задач: канбан с переносом/статусами, календарь, таймлайн и обзор. Навигация к исходной карточке, фильтры, экспорт CSV, диагностика циклов/удалённых зависимостей/дат, ограничения заблокированных объектов и наблюдателя.

- Первая общая регрессия: 61/62. Обнаружен выход первого кадра смешанной сцены за бюджет (127,5 мс, повтор 133,4 мс). Убраны субпиксельные обводки LOD и перерисовка всей оболочки React на каждый сигнал камеры. Итоговый повтор: 62/62 за 13,1 мин, reports/v4-final-browser-regression.log. Смешанная сцена: 43,7 мс первый кадр, 5,3 мс p95, навигация 577,1 мс против 2944,9 мс на 25 шагах. Порог 100 мс сохранён. Длинный штрих: 0,6 мс p95 обработчика пакета 100 точек, 1,8 мс overlay, 2,0 мс commit; 0 полных перерисовок во время ввода. Шесть профилей плавности — без разрывов, расхождение силуэта 0–1,685%.
- Нативный Preview 0.4.0-dev.1 собран за 4 мин 53 с: reports/v4-native-preview-build.log. В отдельном app.lightpen.preview и WebView-профиле созданы гостевая общая копия, получена правка названия/стикера второго клиента, нарисована линия, полученная сервером и вторым клиентом (8 объектов, 2 штриха). Штатное закрытие этого Preview на этом этапе не подтверждено. Пользовательские файлы/профиль не менялись.

## Дальше

Текущий этап ограничен упаковкой и публикацией проверенной беты. Затем, в следующих версиях, остаются документы/богатый текст, контейнеры, диаграммы/mind map, расширенные данные/представления/медиа/импорт/экспорт и остальные направления плана. Полный объём не завершён; зелёные тесты этой беты не означают выполнения всего плана.

Нативный preview запускать с отдельным identifier app.lightpen.preview либо поставляемый бинарный файл с полным локальным LIGHT_PEN_PROFILE_DIR; в обоих случаях задавать отдельный WEBVIEW2_USER_DATA_FOLDER. Не запускать второй экземпляр с тем же identifier поверх работающей пользовательской доски. Пользовательские доски и профиль не использовать как тестовые данные. Сетевые токены/SQLite/резервные копии/логины тестов не добавлять в Git. Серверные данные, boards, reports и builds исключены.
