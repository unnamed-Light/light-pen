# Доступ ИИ в Light Pen 0.5

Light Pen предоставляет локальные команды MCP внешнему помощнику. Модель и аккаунт ИИ выбираются в приложении помощника; ключ API в Light Pen не требуется. Встроенный чат и автоматический выбор модели в этот выпуск не входят. Сам редактор не отправляет доску поставщику ИИ: содержимое, которое помощник читает через инструменты, обрабатывается его приложением и выбранным провайдером.

## Подключение

1. Запустите настольную сборку, откройте «Файл → Доступ ИИ».
2. Выберите чтение или редактирование. При необходимости задайте папку для открытия файлов/новых копий/экспорта и разрешите сетевые действия с общими досками.
3. Нажмите «Включить доступ». Скопируйте конфигурацию в своё приложение MCP. Для Codex отдельно показан вариант TOML; пути формируются из реально запущенного exe и его профиля.
4. Попросите помощника прочитать board_read, выполнить задачу и проверить результат через board_preview. Команды доступны через tools/list, их параметры описаны JSON Schema.
5. «Отключить доступ» отзывает сеанс. Закрытие приложения или перезагрузка его WebView также требуют нового включения. Конфигурацию помощника при этом переписывать не нужно: обнаружение команд работает и без открытой доски.

В Codex сервер настраивается через параметры MCP либо таблицу [mcp_servers.light_pen] в пользовательском или проектном config.toml: command — путь к exe, args — массив из окна Light Pen. Официальная инструкция: [MCP в Codex](https://learn.chatgpt.com/docs/extend/mcp). Этот проект не изменяет глобальные настройки Codex.

Системный выбор папки и ввод пароля/регистрация выполняются человеком в интерфейсе. Агент может открыть страницу аккаунта и продолжить уже сохранённую сессию. Токен приглашения возвращается только при явном создании нового приглашения, с разрешённым сетевым доступом; сессионные и сохранённые токены не возвращаются. Аппаратные события стилуса не эмулируются: агент создаёт редактируемую геометрию штриха.

Координаты объектов задаются в системе документа. Поля endX/endY у линии, стрелки и соединителя — смещения конца относительно x/y объекта, а не абсолютные координаты. Например, x=100, y=50, endX=200, endY=100 задают конец в (300, 150) до применения поворота и привязок. Отрицательные смещения допустимы; положение конца нельзя подставлять в эти поля без вычитания x/y.

Краткая матрица границ доступа:

| Область | Что разрешено в сеансе |
| --- | --- |
| Открытая доска | Чтение и, если разрешено, редактирование; работа с её черновиком и версиями без выбора папки |
| Недавние документы | document/list_recent показывает текущую доску и файлы внутри выбранной папки; document/recent открывает только эти разрешённые документы. Другие недавние черновики не раскрываются и не открываются |
| Библиотека шаблонов | Общая локальная библиотека доступна без папки; перенос шаблона через файл ограничен выбранной папкой |
| Файлы | Открытие других файлов, новые копии и экспорт требуют выбранную папку; замена назначения — явный overwrite=true |
| Закрытие диалога | workspace_ui с action=close закрывает только открытый агентом диалог без активного пользовательского ввода. Ручное переоткрытие снимает принадлежность агенту |
| Общие доски | Требуются отдельное сетевое разрешение сеанса и подходящая роль участника на сервере |
| Повторы запросов | До 2048 квитанций и 16 MiB на сеанс; после исчерпания любого предела нужен новый сеанс |
| Отмена в MCP-клиенте | Не гарантирует остановку уже принятой операции; доступ отзывается через окно Light Pen, завершённые правки доски отменяются обычным undo |

## Транзакции и параллельная работа

Для изменяющих инструментов нужны session, documentId, expectedRevision и уникальный requestId. Значения session/documentId/revision возвращает board_read; revision передаётся как expectedRevision. При изменении доски агент перечитывает её и формирует новую команду. Одинаковый requestId с идентичным запросом возвращает прежний результат; иное содержимое с тем же ключом отклоняется.

Если получен определённый отказ, например BUSY или REVISION_CONFLICT, после устранения причины используйте новый requestId: квитанция прежней попытки сохраняет её результат. Тот же requestId нужен при потере ответа, когда неизвестно, была ли операция выполнена.

edit_batch готовит изменения отдельно, проверяет модель/изображения/формулы, затем делает один commit. Ошибка в любом шаге не применяет часть пакета. Commit проходит обычную историю, автосохранение и CRDT; собственная отмена сохраняет чужие изменения. Файловые/сетевые операции — отдельные инструменты, они не маскируются под атомарную транзакцию документа. Успешный commit не означает завершённую серверную запись: статус и unconfirmed читаются через collaboration/status.

Активный жест, текстовый ввод, модальный редактор и незавершённая операция дают BUSY. Нельзя прервать ввод человека ради команды агента. Исключение для workspace_ui/close ограничено диалогом, который открыл агент: активное поле ввода человека блокирует закрытие, а ручное переоткрытие диалога снимает принадлежность агенту.

Отмена запроса в MCP-клиенте не гарантирует остановку операции, уже принятой приложением. Для отзыва доступа используйте «Файл → Доступ ИИ → Отключить доступ». При отключении прекращается приём новых команд и отзывается ожидание ответа; уже зафиксированная правка сама не отменяется и доступна обычному undo. Если результат потерян из-за обрыва, повторять следует тот же requestId в том же сеансе. После смены сеанса требуется новое чтение и оценка результата.

Журнал requestId ограничен 2048 квитанциями и 16 MiB (16 × 1024 × 1024 байт) на сеанс. После исчерпания любого предела нужна новая сессия; старые квитанции молча не вытесняются. Перезагрузка WebView отзывает прежний доступ: новый frontend не имеет старого журнала и не принимает прежние запросы до нового включения.

## Локальный канал и ограничения

Один exe запускается как приложение или с --mcp как stdio-процесс. Поддерживается инициализация MCP 2025-11-25 и предыдущих совместимых версий; современный клиент может использовать предусмотренный протоколом fallback на initialize. Статический каталог скомпилирован из того же TypeScript-контракта, что использует редактор. npm run build/dev обновляет его перед запуском.

Мост обращается к временному порту только на 127.0.0.1 по ограниченным JSON-строкам с отдельной аутентификацией. Секрет канала хранится в agent-session.dpapi с защитой текущего Windows-пользователя и не входит в конфигурацию помощника. Разрешены только MCP tools/resources, никакого общего invoke, eval, терминала или доступа к vault. Доска, ссылки и содержимое файлов считаются недоверенными данными.

Запрос до 32 МБ, ответ до 8 МБ, обычный текстовый результат до 4 МБ; чтение постраничное. PNG-просмотр ограничен 1600 пикселями по стороне и дополнительно уменьшается при большом объёме. Пакет — до 200 операций; файл сохраняет прежние ограничения модели 64 МБ. Новые файлы пишутся только в выбранной папке; существующее назначение требует overwrite=true. Гонка появления назначения при overwrite=false не заменяет чужой файл.
