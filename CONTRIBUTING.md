# Участие в Light Pen

Спасибо за помощь проекту. Обсудить идею или сообщить об ошибке можно в GitHub Issues. Для ошибки укажите версию приложения, Windows, действия воспроизведения и ожидаемый результат. Прикладывайте только специально подготовленные примеры без личных данных.

Перед работой прочитайте AGENTS.md и docs/architecture.md. Для Windows нужны Node.js, Rust MSVC, C++ Build Tools, Windows SDK и WebView2. Установите зависимости командой npm ci; режим разработки — npm run tauri -- dev.

Перед pull request выполните npm run build, npm test и cargo test --manifest-path src-tauri/Cargo.toml --lib. Для изменения интерфейса установите Chromium через npx playwright install chromium --only-shell и выполните npm run test:e2e. Для пера, камеры и renderer сохраните измерения плавности и производительности. Нативные изменения проверяйте в собранном Windows-приложении.

Нативные QA-скрипты работают с реальным хранилищем приложения. Запускайте их только в отдельном тестовом профиле Windows или на данных, подготовленных для проверки. Обычные модульные и браузерные тесты не требуют пользовательских досок.

Не включайте в коммиты личные доски, черновики, ключи, локальные настройки, node_modules, reports или готовые сборки. Исходный код проекта распространяется по MIT; сторонние компоненты сохраняют свои лицензии.
